# Changelog

2026-08-30: Schedules page — teacher schedules now show the whole day, not just classes. Every period a teacher has is filled in exactly as the scheduler shows it: PREP, Recess/Lunch (with Duty / No Duty), the P9 Extra Help/Advisory block, the HR homeroom row, Wednesday Electives/Assembly, and "off" for periods a part-timer doesn't work. This is computed read-only from the saved schedule using the same lunch/prep logic the scheduler uses (verified to match the scheduler's By-teacher view exactly), so nothing needs re-generating. Also: a teacher who doesn't teach a timetabled subject — a PreK or lower-grade homeroom teacher like Donnelly — used to come up blank. Now their page shows their homeroom group's full week: their homeroom periods plus where their students go for specials (Music, PE, Spanish, etc.), so they finally have a real schedule. (The scheduler's own By-teacher dropdown stays subject-teachers-only by design — the Schedules page is where any staff member's week lives.) Students now show an HR homeroom row too.
2026-08-29: Scheduler — added an HR (homeroom) period before P1, 8:05–8:20. It appears at the top of the By-teacher, By-class, and Master views and on the printable one-page board. It's a non-academic block: the generator never schedules classes into it, so generation is unchanged (still 279/279). In the By-teacher view each day's HR cell is editable and defaults to "Homeroom" — type a different role (e.g. a duty) and it's stored with that staff member, so it stays on their personal schedule and doesn't affect anyone else. Class and master views show "Homeroom." Edits save with the schedule (💾 Save). (Not yet shown on the student/teacher Schedules pages or the .xlsx/.csv exports — can add on request.)
2026-08-29: Favicon now shows on every portal page (added the icon tag to the Scheduler and a /favicon.ico fallback route).
2026-08-28: New — student & teacher weekly schedules (Schedules page + on each teacher's dashboard). The scheduler still owns all the rules and produces the master timetable; these new views just read that finished timetable and cross it with the Classes-page rosters to show each person's week. A teacher's "My Classroom" home page now shows their own weekly schedule at the top (pulled from the generated timetable, class names and rooms per period), and clicking any student opens that student's weekly schedule. A new read-only Schedules page (/schedule) lets any signed-in staff look up any teacher's or student's week: a teacher view shows their grid plus their classes with rosters (click a student to jump to that student's schedule), and a student view shows their grid — their timetabled classes plus Recess/Lunch, Wednesday Electives/Assembly, and the P9 block — with a list of their classes and teachers. Both have a Print/Save-PDF button. Student schedules are built from the real section rosters, connected to the scheduler by the same match key the reconciliation page uses, so a student's week reflects exactly the classes they're enrolled in (Gold/Blue/White split included). Nothing here is editable and nothing touches the scheduler's generation. Backed by one new read-only endpoint (/api/schedule/rosters).

2026-08-28: New page — Class Reconciliation (Classes page → "Check vs. Scheduler", or /reconcile). A read-only check that compares every class the Scheduler timetables against the sections built on the Classes page, so the two can be lined up before generating per-student and per-teacher schedules. It matches on grade + subject + section identity (whole-grade, Gold/Blue/White, or teacher name for 6th–8th math) and sorts everything into: matched classes, "split mismatches" (both sides schedule the same grade+subject but disagree on how it's split), on-the-scheduler-but-not-in-Classes, and in-Classes-but-not-on-the-scheduler (support blocks like Study Skills and OT land here, as expected). It only reads /api/scheduler and /api/sections and writes nothing. On the current data it matches 107 of 109 scheduler classes; the two flagged are 6th-grade PE and 6th-grade Spanish, where the scheduler has a whole-grade block but the Classes page has Gold/Blue sections. Gated behind the Classes permission. Print/Save-PDF button included.

2026-08-28: Classes page — added a Grade filter next to the Type filter, so you can narrow the class list to a single grade (and combine it with Type, e.g. 7th-grade Subject classes). "All grades" shows everything as before.

2026-08-28: Classes → Gold & Blue — the student list no longer sits in a short internal scroll-box. It was capped at ~62% of the screen height with its own scrollbar, so a grade with more students than fit (e.g. 23 in 7th) looked like it was only showing the first ~10 unless you scrolled inside that box. The list now grows with the page, so every student in the grade is visible by scrolling normally.

2026-08-27: Scheduler — 6th/7th/8th math alignment is now guaranteed identical on every browser. The earlier approach re-solved under a time limit to align the split math, which meant a slower browser (Safari) could run out of time and fall back to a misaligned draft — so Chrome and Safari gave different results. Math is now placed on a fixed grade-wide period grid pinned in code (the same mechanism as the 7th-grade Science lock): 6th at 3rd period (moved to 7th period on Wednesday, since 3rd is closed school-wide), 7th at 6th period, 8th at 5th period, every day including Friday (8th sits at 5th so it clears the 7th/8th lunch at 4th period). No re-solve, no timing, no browser dependence — every Generate lines Gold/Blue/White up the same way, and it still comes out complete with McLeod keeping a daily lunch (verified across Quick/Standard runs).

2026-08-27: Scheduler — fixed a timing bug where a generation could leave a couple of classes unplaced on a slower machine (while completing fine on a faster one). The new hard math-alignment runs the solver in two passes, and the first pass wasn't being given enough of the time budget to reliably finish. It now gets the majority of the time (the loop still stops the instant it finds a complete draft, so easy runs aren't slower), and if the alignment pass ever runs short it falls back to the complete draft instead of leaving classes unplaced. Verified complete + fully aligned across repeated Standard-effort runs.

2026-08-27: Deploys now take effect without a hard-refresh. The app was letting browsers cache the admin pages (HTML/JS), so after a deploy staff could keep running the old code until they manually hard-refreshed — this is why one person's scheduler followed the newest rules while another's still generated with the previous ones (e.g. the old 7th-grade Friday math exception). Pages now tell the browser to revalidate on every load, so the current version loads automatically; nothing else changes and unchanged files still return a cheap "not modified."

The Add/Edit Session box got the same narrowing — a Grade box beside Student — and when you open an existing session it opens on that student's grade. Grades list in school order (JPK, SPK, K, 1–8), not alphabetically.

2026-08-23: New page — In Session Special Services Schedule (People menu → Special Services). A second, much simpler schedule for during-the-school-day support: periods P1–P8 down the side, Monday–Friday across the top, and each period/day cell holds any number of sessions. 2026-08-23: Scheduler save is now conflict-safe. Previously, if two editors had the scheduler open at once, a stale tab could silently overwrite a newer save (this is how deleted requirements like the bad JPK/Math rows kept reappearing). The server now versions each saved schedule and rejects a save from a tab that loaded an older version, and autosave has been removed — the schedule saves only when you click 💾 Save. An out-of-date tab shows a red "changed in another session — reload to get the latest" banner and is blocked from saving until it reloads, so no one can clobber someone else's work. Unsaved edits now tint the Save button and warn before you navigate away.
